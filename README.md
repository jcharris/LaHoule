 # 🌊 LaHoule 3D: Interactive Seakeeping & RAO Visualizer

**LaHoule 3D** is a lightweight, zero-installation, browser-native 3D demonstration tool built for exploring **ship motions, encounter frequency Doppler shifts, and Response Amplitude Operators (RAOs)** in real time.

---
